# Rainy Days – HTML & CSS

## Description
Rainy Days is an e-commerce website built as a front-end project focusing on semantic HTML and responsive CSS design.
The project showcases structured layouts, product pages, and a checkout flow without JavaScript functionality.

## Built With
- HTML5
- CSS3

## Features
- Responsive layout
- Product listing and product detail pages
- Cart popup page
- Checkout page
- Semantic structure and accessibility considerations
